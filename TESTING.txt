NameplateSCT-Vanilla v0.5.0-test

TESTING.md is the canonical test matrix for the current build.

Quick native-combat smoke test:
1. Enable enemy nameplates.
2. /np clear
3. /np status
4. Confirm "native combat backend: active (5/5 required; ... optional)" if possible.
5. Target one visible enemy.
6. Perform several white attacks and at least one ability/spell.
7. If available, test a crit, miss/dodge/parry/resist, and a DoT tick.
8. /np errors
9. /np dump 50

Expected log flow:
[NATIVELOG] -> [PARSED] -> [DISPLAY]

Any [UNMATCHED] entry is useful parser test data and should be preserved exactly.

v0.5.0-test focus:
- target: scale 1.00, alpha 1.00, HIGH strata
- off-target: scale 0.75, alpha 0.72, MEDIUM strata
- use /np testoff with two visible nameplates for a synthetic off-target check
- real DoT ticks after switching target are the preferred off-target combat test
- focus classification uses the resolved frame/GUID, not name alone
- existing fountain and POW trajectories remain unchanged
- late/killing-blow recent-resolution cache remains deferred
