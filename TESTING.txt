NameplateSCT-Vanilla v0.4.3-test

TESTING.md is the canonical test matrix for the current build.

Quick native-combat smoke test:
1. Enable enemy nameplates.
2. /np clear
3. /np status
4. Confirm "native combat backend: active (5/5 events)" if possible.
5. Target one visible enemy.
6. Perform several white attacks and at least one ability/spell.
7. If available, test a crit, miss/dodge/parry/resist, and a DoT tick.
8. /np errors
9. /np dump 50

Expected log flow:
[NATIVELOG] -> [PARSED] -> [DISPLAY]

Any [UNMATCHED] entry is useful parser test data and should be preserved exactly.

v0.4.3-test focus:
- native Vanilla CHAT_MSG_* outgoing-combat parsing
- localized parsing from Blizzard global combat strings
- normalized autoattack / ability / spell / periodic / miss events
- no duplicate SCT when RAW_COMBATLOG is also present
- existing native nameplate resolution and animations remain unchanged
